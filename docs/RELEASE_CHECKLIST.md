# FullGram — Чек-лист перед выпуском сборки (Фаза 0)

Каждая ветка фичи мержится в `release/next` только при зелёном CI (`tools/ci_checks.py` + успешная сборка `.ipa`).
Перед раздачей `.ipa` пользователям обязательно прогнать ручной smoke-тест на реальном iPhone.

## 1. Базовый smoke-тест
- [ ] Холодный запуск приложения без вылета
- [ ] Вход в аккаунт / открытие существующей сессии
- [ ] Открытие **Настройки → FullGram**
- [ ] Переключение между аккаунтами (если добавлено >1)
- [ ] Отправка и получение текстового сообщения, фото и голосового

## 2. Проверка вкладок FullGram (без чёрного экрана)
Открыть каждую категорию и убедиться, что экран отрисовался и элементы кликабельны:
- [ ] **Оформление** → Шрифты, Темы (предпросмотр), Дизайн, Иконки приложения, Анимированные рамки, Стили ников
- [ ] **Чаты** → Удалённые и изменённые, Отправка, Перевод, Меню сообщений, Реакции
- [ ] **Приватность** → Режим призрака, Приватный режим, Деятельность и следы
- [ ] **Безопасность** → Face ID, Скрыть номер, Размытие в трее, Анти-скам (+ гайд)
- [ ] **Анти-скам**
- [ ] **Медиа и Аудио** → Голос, Кружки и камера, Микшер, Источники текстов песен
- [ ] **Плагины** → Редактор плагина, Маркет, Справка по API
- [ ] **ИИ Ассистент** → Главный экран (hero-карточка), Промпт безопасности
- [ ] **Прочее** → Основное, Бэкап

## 3. Проверка критических исправлений (Фаза 1)
- [ ] **Безопасность админки:** без валидного подписанного токена (`/auth` в боте) или `initData` сервер возвращает `401 Unauthorized` на `/admin/*` и `POST /cosmetics`
- [ ] **Face ID:** заблокировать чат → открыть по Face ID → выйти из чата → открыть снова → **Face ID запрашивается повторно**; свернуть приложение в фон → вернуться → **Face ID запрашивается повторно**
- [ ] **Режим безопасности / Приватный режим:** в обычном режиме номер, `@username` и превью чатов **видны нормально**; при запуске записи экрана (`UIScreen.isCaptured`) — **автоматически скрываются**
- [ ] **Старый дизайн:** включает полную нижнюю панель (`TabBarNode`), классические текстовые вкладки папок с подчёркиванием (`ChatListFilterTabContainerNode`) и плоские панели без стекла; при сбое запуска `FullGramDesignWatchdog` автоматически откатывает дизайн к стандартному (и есть удалённый kill-switch `classicDesign` в `/config.json`)
- [ ] **Feature Flags:** `/config.json` доступен и позволяет удалённо отключить сломанную функцию без перевыпуска `.ipa`
