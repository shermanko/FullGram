# FullGram v1.5.2

> Расширенный iOS-клиент Telegram с модулем приватности, Анти-скамом, локальным AI-ассистентом, системой плагинов (Lua / Python / Rust + нативный GUI), полной косметикой Discord (663 рамки + 329 анимаций профиля), NFT Grant Studio, классическим дизайном Telegram и ускорением загрузки медиа.

---

## Основные возможности

### Косметика Discord, NFT и профили
- **Косметика Discord** — более **663 анимированных рамок аватара** и **329 анимаций открытия профиля (Profile Effects)** из официального каталога Discord с поиском, живым предпросмотром и облачной синхронизацией (видно всем пользователям FullGram).
- **Кастомные рамки** — загрузка собственной PNG/APNG/GIF рамки из фотоплёнки iPhone или по прямой `https://`-ссылке.
- **Стиль и подсветка ника** — выбор цвета (палитра / HEX / готовые пресеты) и яркое неоновое свечение ника в профиле и списке чатов.
- **NFT Grant Studio** (админ-панель) — выбор коллекции Telegram Gifts в компактной 4-колоночной сетке, настройка модели, фона, узора и номера `#` с живым превью, отображением в профиле у всех пользователей FullGram и уведомлением в чате.
- **Бейджи FullGram** — роли и кастомные эмодзи-бейджи с 4-секундным верхним баннером и серверной Telegram-авторизацией (`initData` / `/auth`).

### Оформление и классический дизайн
- **Классический дизайн Telegram** — классический нижний таб-бар и классические вкладки папок с подчёркиванием + встроенный `Watchdog` автоотката при сбое запуска.
- **Кастомизация** — локальные шрифты (`Minecraft`, `JetBrains Mono`, `Montserrat` и др.), OLED-режим, конструктор тем и альтернативные иконки приложения (включая *Маскот*).
- **Поиск по настройкам** и **единый бэкап `.fullgram`**.

### ИИ Ассистент и маскот
- **Подключение по API-ключу** — OpenAI, OpenRouter, Groq, Anthropic Claude, Google Gemini или локальный сервер (Ollama, LM Studio). Ключи шифруются в iOS Keychain.
- **Реальная локальная статистика** — ИИ автоматически получает блок `[VERIFIED_LOCAL_STATS]` по текущему чату (сообщения сегодня/за неделю, участники, ГС, кружки, медиа) и общую статистику аккаунта (диалоги, непрочитанные, активность сегодня) для закладок `📊 Статистика`, `📅 Сегодня`, `✨ Сводка чата`.
- **Команда `.ai` в любом чате**, сворачиваемое перетаскиваемое окно и плавающий питомец-маскот.
- **Защита от Prompt Injection** (`[UNTRUSTED_CHAT_DATA]`), запрет утечки секретов и ручное подтверждение любых действий.

### Система плагинов (Lua, Python, Rust + GUI)
- Изолированные встроенные VM для **Lua 5.x**, **Python 3** и **Rust** (`maxSteps = 120 000`, `maxCallDepth = 64`, потокобезопасность).
- Двусторонний графический UI (`fullgram.open_ui` + `on_ui_event`) — плагины могут открывать нативные экраны вместо спама в чат.
- **BetKing / Betona Casino GUI** (`.casino`, `.zeus`, `.dogs`, `.slots`, `.crash`, `.roulette`, `.coin`) — анимированные 5×3/3×1 слоты, Live Crash с графиком ракеты 60fps, крутящаяся рулетка и 3D-монетка.
- Встроенные плагины: **Информация о чате** (`.plug info-chat`), **Дедлайны** (`.dl` с GUI), **Шаблоны** (`.tpl`), **Заметки** (`.note`), **Исправление раскладки** (`.fix`), **Анти-опечатки**.

### Приватность, Безопасность и Медиа
- **Режим призрака** — скрытие чтения, онлайна, набора текста, прогресса загрузки и отложенное чтение.
- **Приватный режим (режим стримера)** — автоматическое скрытие превью, `@username` и номера телефона только во время записи/демонстрации экрана.
- **Face ID / Touch ID блокировка чатов** — надёжная повторная блокировка при сворачивании (`didEnterBackground`), размытие экрана в трее.
- **Анти-скам** — проверка фишинговых ссылок (Punycode, `@`-маскировка, IP-хосты, Mini App параметры), **Анти-офер**, **Анти-OTC** и гайд **«Не попадись»**.
- **Голос, кружки и медиа** — модулятор голоса + автозапикивание матов, маски лица в видеокружках, бесплатная локальная расшифровка ГС, сохранение одноразовых медиа и ускоренная загрузка.
